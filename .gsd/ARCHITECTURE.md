## Overview

**ESEC Transport** is a cross-platform mobile and web application built with **React Native / Expo** and **Supabase (PostgreSQL + Realtime)** for Erode Sengunthar Engineering College. It provides real-time college bus location broadcasting, timetable navigation, driver shift management with continuous background geolocation, and administrative route configuration.

### 3. Services & Infrastructure Layer (`src/services/`)

- **`supabaseClient.js`** (`src/services/supabaseClient.js`)
  - **Purpose:** Initializes `@supabase/supabase-js` client with AsyncStorage persistence and 10 events/sec realtime parameters.

- **`locationService.js`** (`src/services/locationService.js`)
  - **Purpose:** Coordinates `expo-location` background services:
    - `timeInterval: 10000`, `distanceInterval: 0`
    - Dynamic deadline calculation: `Math.max(arrivalDate + 30 min, now + 2 hours)`
    - Task registration safety: stops existing tasks before re-registering to ensure updated options apply.

- **`taskManager.js`** (`src/services/taskManager.js`)
  - **Purpose:** Background task definition for `TaskManager.defineTask(APP_CONFIG.LOCATION_TASK_NAME)`. Runs headlessly during locked phone states. Upserts GPS fixes into `bus_location` and self-terminates when the stored deadline expires.

- **`authService.js`** (`src/services/authService.js`)
  - **Purpose:** Session management and PIN authentication. Evaluates master admin, Supabase admin table, and exact matching against `buses.driver_phone`.

## Data Flow

```
1. DRIVER BROADCAST FLOW:
   Driver clicks "Share Location" in DriverTracking
   ──► locationService.startBackgroundTracking(busId)
   ──► Sets 'esec_active_driver_bus_id' & 'esec_tracking_deadline' in AsyncStorage
   ──► Sets buses.is_tracking = true in Supabase
   ──► Registers TaskManager background loop
   ──► OS Location Provider sends GPS fixes to taskManager.js
   ──► taskManager upserts { bus_id, latitude, longitude, speed, updated_at } to `bus_location`

2. PARENT LISTENER FLOW:
   Parent opens ParentHome ──► Selects Bus ──► BusTracker
   ──► useLocation subscribes to Supabase Realtime channel `realtime_bus_${busId}`
   ──► Fallback poller fetches `bus_location` row every 15s
   ──► LocationDisplay feeds coordinates into getBusStatus()
   ──► Live indicator switches to "LIVE GPS" with live speed and timestamp
```
